# mdlinkcheck

Консольная утилита, которая находит битые ссылки в Markdown-документации.

![Python](https://img.shields.io/badge/python-3.9+-blue) ![License](https://img.shields.io/badge/license-MIT-green)

Документация устаревает незаметно: файлы переименовывают, сайты закрываются. `mdlinkcheck` проверяет все ссылки за один запуск и возвращает код выхода, который можно использовать в CI.

## Возможности

- Проверка локальных ссылок на файлы и внешних ссылок (HTTP/HTTPS)
- Рекурсивный обход папок
- Пропуск блоков кода, инлайн-кода и якорей (`#раздел`)
- Вывод в текстовом формате или JSON
- Работает без сторонних зависимостей

## Требования

- Python 3.9 или новее

## Установка

```bash
git clone https://github.com/username/mdlinkcheck.git
cd mdlinkcheck
```

Дополнительных пакетов устанавливать не нужно.

## Быстрый старт

Проверьте все `.md`-файлы в папке `docs`:

```bash
python mdlinkcheck.py docs
```

Пример вывода:

```
docs/guide.md:12  old-page.md  ->  файл не найден
docs/index.md:5  https://example.com/gone  ->  404

Проверено ссылок: 18, битых: 2
```

## Параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `paths` | Файлы или папки для проверки | — |
| `--timeout N` | Таймаут запроса в секундах | `10` |
| `--ignore TEXT` | Пропускать ссылки, содержащие `TEXT` (можно повторять) | — |
| `--offline` | Проверять только локальные ссылки | выключено |
| `--format` | Формат вывода: `text` или `json` | `text` |
| `--version` | Показать версию | — |

## Коды выхода

| Код | Значение |
|-----|----------|
| `0` | Битых ссылок нет |
| `1` | Найдена хотя бы одна битая ссылка |
| `2` | Файлы не найдены |

## Использование в CI

```yaml
- name: Проверка ссылок в документации
  run: python mdlinkcheck.py docs --offline
```

## Частые проблемы

**Внешняя ссылка помечена битой, хотя в браузере открывается.** Некоторые сайты блокируют автоматические запросы. Добавьте её в исключения: `--ignore example.com`.

**Проверка идёт долго.** Уменьшите `--timeout` или используйте `--offline` для локальных ссылок.
