# Участие в проекте

Спасибо, что хотите улучшить `mdlinkcheck`.

## Как сообщить об ошибке

Создайте issue и укажите:
1. Версию Python и ОС.
2. Команду, которую вы запускали.
3. Что ожидали и что получили.

## Как предложить изменение

1. Сделайте fork и создайте ветку: `git checkout -b fix/описание`.
2. Внесите правки и добавьте тест.
3. Убедитесь, что тесты проходят: `python -m unittest discover -s tests`.
4. Обновите документацию и `CHANGELOG.md`, если меняется поведение.
5. Отправьте pull request с описанием изменений.

## Правила для документации

- Один шаг в инструкции — одно действие.
- Команды и имена файлов оформляйте как код.
- Примеры должны запускаться: проверяйте их перед отправкой.
