# FAQ

## Почему рабочая ссылка помечена как битая?

Часть сайтов блокирует автоматические запросы или требует авторизацию. Добавьте такой адрес в исключения:

```bash
python mdlinkcheck.py docs --ignore example.com
```

## Проверяются ли ссылки на разделы внутри страницы?

Нет. Якоря (`#раздел`) отбрасываются. Проверяется только наличие самого файла.

## Проверяются ли ссылки в блоках кода?

Нет. Пропускается всё, что находится между строками ```` ``` ````, а также текст в одинарных обратных кавычках.

## Как использовать утилиту в CI?

Запустите её отдельным шагом. Если найдены битые ссылки, код выхода будет `1`, и шаг завершится ошибкой.

## Поддерживаются ли ссылки в HTML-тегах и reference-стиле?

Пока нет. Поддерживается только формат `[текст](адрес)`. См. [план развития](../CHANGELOG.md).
