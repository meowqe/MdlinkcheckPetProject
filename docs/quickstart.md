# Быстрый старт

Из этого руководства вы узнаете, как установить `mdlinkcheck` и проверить свою документацию.

## Прежде чем начать

Убедитесь, что установлен Python 3.9 или новее:

```bash
python --version
```

## Шаг 1. Получите утилиту

```bash
git clone https://github.com/username/mdlinkcheck.git
cd mdlinkcheck
```

## Шаг 2. Запустите проверку

Укажите папку с документацией:

```bash
python mdlinkcheck.py docs
```

Если битых ссылок нет, вы увидите:

```
Проверено ссылок: 18, битых: 0
```

## Шаг 3. Исправьте найденные ошибки

Каждая строка отчёта содержит файл, номер строки, ссылку и причину:

```
docs/guide.md:12  old-page.md  ->  файл не найден
```

Откройте `docs/guide.md`, перейдите к строке 12 и поправьте ссылку.

!!! tip "Совет"
    Для быстрой проверки без интернета добавьте `--offline`: утилита проверит только локальные ссылки.
