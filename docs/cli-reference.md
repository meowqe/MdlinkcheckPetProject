# Справочник команд

## Синтаксис

```bash
python mdlinkcheck.py [параметры] paths...
```

## Аргументы

| Аргумент | Описание |
|----------|----------|
| `paths` | Один или несколько файлов или папок. Из папок рекурсивно берутся все `.md`-файлы. |

## Параметры

### `--timeout N`

Время ожидания ответа от сайта в секундах. По умолчанию: `10`.

```bash
python mdlinkcheck.py docs --timeout 5
```

### `--ignore TEXT`

Пропускает ссылки, в которых встречается `TEXT`. Параметр можно указывать несколько раз.

```bash
python mdlinkcheck.py docs --ignore localhost --ignore example.com
```

### `--offline`

Проверяет только локальные ссылки. Внешние пропускаются.

### `--format {text,json}`

Формат вывода. По умолчанию: `text`.

Пример JSON-вывода:

```json
[
  {
    "file": "docs/guide.md",
    "line": 12,
    "link": "old-page.md",
    "ok": false,
    "detail": "файл не найден"
  }
]
```

| Поле | Тип | Описание |
|------|-----|----------|
| `file` | строка | Файл, где найдена ссылка |
| `line` | число | Номер строки |
| `link` | строка | Адрес ссылки |
| `ok` | логическое | `true`, если ссылка работает |
| `detail` | строка | Код ответа или причина ошибки |

### `--version`

Выводит версию утилиты.

## Коды выхода

| Код | Значение |
|-----|----------|
| `0` | Битых ссылок нет |
| `1` | Найдена хотя бы одна битая ссылка |
| `2` | Указанные файлы не найдены |
